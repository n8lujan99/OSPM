# Changelog

## OSPM 3.0.0

First public release of OSPM.

OSPM v3 establishes the public codebase for the actively developed
orbit-superposition modeling framework.

Major capabilities include:

- Python/Julia model execution
- configurable galaxy profiles
- stellar-force grids
- three-dimensional tracer-density constraints
- LOSVD observable construction
- Karl-style observable mapping
- orbit-library generation
- orbit-weight optimization
- automated parameter-space exploration
- local and Slurm execution support
- Draco, Segue 1, and Carina galaxy configurations

The public v3 tree was prepared from the internal Classic-OSPM development
lineage.
